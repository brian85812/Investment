# 年線重返多頭條件顯示核對（2026-11-12）

使用者指出股價已站上畫面加碼點卻沒有升檔。按正式 build_static 的參數、真實行情及 app.compute_signal 重算，11/11的QQQ收盤690.3800049、5MA669.5279907、220MA675.0407784、60MA717.7779327、8日突破691.9500122。公開網站與重新計算均維持防禦0.8x。

正式重返多頭條件是「收盤 >= 220MA 且快線 >= 220MA」。當日股價已達成，但5MA仍低於220MA，因此防禦優先分支仍生效。多頭階梯升檔另有嚴格突破通道、冷卻及美股D1（5MA >= 60MA）要求，不能把價格站上220MA解讀為已產生升檔訊號。

台股同資料日收盤236.60、8MA227.4375、220MA210.6667、15日突破249.0500；多頭成立，但沒有突破升檔通道，並在10/30減碼後冷卻餘2交易日，維持2.8x。台美均以最新已完成交易日為準。

缺陷在前端：防禦狀態的欄位標作「加碼突破門檻」，內容卻只寫「站上年線 > 價格」，漏了快線條件且比較運算子也不完整。現在標籤區分防禦轉多頭與階梯升檔，並完整列出兩個 >= 條件；快線仍低於年線的狀態取自後端原始精度理由，不由四捨五入數字反推。E3b進場、維持與重返多頭也分別列明。
